# 💖 Date Invite App

A fun interactive date invitation app built with Next.js, Framer Motion, Tailwind CSS, and Supabase.

The app asks the ultimate question:

> "Will you go on a date with me? 🥺👉👈"

If the answer is YES:
- 🎉 Celebration confetti appears
- 📅 User selects a date
- ⏰ User selects a time
- 🎯 User chooses activities
- 💌 Data gets stored in Supabase

The NO button?
Emotionally unavailable. 😭

---

## ✨ Features

- 💖 Animated YES button growth
- 🏃 Moving NO button
- 🎊 Confetti celebration effects
- 📅 Date picker
- ⏰ Time picker
- 🎯 Activity selection
- ✅ Form validation
- 🔴 Error highlighting
- ☁️ Supabase database integration
- 🎨 Responsive modern UI
- ⚡ Smooth Framer Motion animations
